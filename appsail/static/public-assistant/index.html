File a Complaint / ದೂರು ದಾಖಲಿಸುವುದು

  1. Visit your jurisdictional police station, or use the Karnataka State Police public portal for an online complaint / e-FIR where available.
  2. Carry a valid photo ID and, if any, documents related to the incident.
  3. Clearly state what happened, where, and when. Ask for the complaint / FIR number before you leave.
  4. For a cognizable offence the station must register an FIR; you are entitled to a free copy of it.
  5. If a station declines to register, you may approach the jurisdictional senior officer (ACP / DCP) or the Superintendent of Police.
